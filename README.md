# Lokval

Ранний коммерческий проект (2023): многостраничный сайт-каталог каминов.

- главная, каталог по видам, карточки каминов, страница «О компании»
- форма обратной связи на Formik
- слайдеры на Swiper, кнопка «наверх», адаптивная вёрстка
- стили на styled-components, состояние в Redux

`React 18` `TypeScript` `Redux` `React Router 6` `styled-components` `Formik` `Swiper`

## Запуск

```bash
yarn install
yarn start
```
